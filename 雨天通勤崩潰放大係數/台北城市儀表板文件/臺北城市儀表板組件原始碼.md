# 臺北城市儀表板前端組件逆向指南

## 0. 研究範圍與結論

本文件逆向目標是 `https://citydashboard.taipei/dashboard` 與本機原始碼 `Taipei-City-Dashboard-FE`。線上站台是 Vue SPA，直接抓 HTML 只能看到「請開啟 JavaScript 以使用本儀表板」，因此可靠逆向依據以本機前端原始碼為主，線上 URL 作為公開入口確認。

核心結論：

- 臺北城市儀表板不是一般 landing page，而是密集型營運 dashboard。
- 視覺語言是深色、低裝飾、5px 小圓角、細邊框、高資訊密度。
- 組件不是自由 HTML，而是 `DashboardComponent.vue` 依 `config` 動態掛載 chart component。
- 圖表主要靠 ApexCharts；地圖靠 Mapbox GL，進階空間圖層靠 deck.gl、Turf、Three.js。
- 若要把「捷運最後一哩服務健康度」塞進原儀表板，最小阻力做法是用既有 `BarChart` / `ColumnChart` / `MapLegend` + Mapbox `circle`/`line` 圖層；若要保留我們現在的捷運路網 SVG，需要新增自訂 chart type。

## 2. 技術棧

`package.json` 顯示：

- Framework：Vue 3 + Vite。
- State：Pinia。
- Router：Vue Router。
- HTTP：Axios。
- Chart：ApexCharts + vue3-apexcharts。
- Map：Mapbox GL JS。
- Advanced map：deck.gl、Turf、Three.js、GLTFLoader。
- Icons：Material Icons Round 字型。
- Utility：VueUse fullscreen、lodash debounce、hls.js。

這代表「組件」要跟 Vue/Apex/Mapbox 的資料格式對齊，而不是單純塞一個 iframe 就能完全融入原生互動。

## 3. 全域設計語言

來源：`src/assets/styles/globalStyles.css`

### 3.1 色彩 token

```css
--color-background: #090909;
--color-border: #494b4e;
--color-highlight: #5a9cf8;
--color-normal-text: white;
--color-complement-text: #888787;
--color-component-background: #282a2c;
--color-overlay: rgba(0, 0, 0, 0.65);
--color-taipei: #1411AC;
--color-metrotaipei: #ac7811;
```

設計解讀：

- 背景近黑，不使用漸層、不做卡片陰影堆疊。
- 元件底色是深灰 `#282a2c`，不是純黑。
- 主行動色固定為亮藍 `#5a9cf8`。
- 次要文字固定灰色 `#888787`。
- 邊框色偏亮灰 `#494b4e`，用來分隔密集資訊。

### 3.2 字體與尺寸

```css
--font-xl: 1.5rem;
--font-l: 1.25rem;
--font-m: 18px;
--font-ms: 1rem;
--font-s: 0.75rem;
--font-icon: "Material Icons Round";
```

文字策略：

- 卡片標題多用 `18px`。
- 說明、資料來源、tag 多用 `0.75rem`。
- 不用 hero-scale typography。
- Icons 不是 SVG icon library，而是 Material Icons 字型文字，例如 `map`、`insights`、`favorite`。

### 3.3 形狀與間距

- 圓角幾乎固定 `5px`。
- 卡片 padding 多用 `var(--font-m)`，也就是 18px。
- 元件 grid gap 多用 `var(--font-s)` 或 `var(--font-m)`。
- Scrollbar 幾乎隱藏，只有局部資訊面板會顯示細 scrollbar。

### 3.4 動態語言

- Hover 多是 opacity 或 color 0.2s。
- Dialog 使用淡入 + 往下滑入。
- Loading 是小型圓形 spinner。
- District / icon 類圖表用短延遲 cascade animation。

`SettingsBar.vue`：

- 下方 border。

- MapView 顯示「新增地標 / 雙擊以建立地標」按鈕。

```text
>=2200px     : 5 欄
```

## 5. DashboardComponent 核心卡片

來源：`src/dashboardComponent/DashboardComponent.vue`

這是所有 dashboard 組件的外殼。任何新指標若要融入官方風格，第一優先是符合它的 config 與 slotless chart 架構。

### 5.2 卡片模式

```text
default : 一般 dashboard 卡片，高約 330-500px，隨螢幕變高。
large   : more-info dialog 裡的大卡，高約 350-520px。
half    : 地圖圖層 dashboard 或 map-layers 類半高卡，高約 180-275px。
map     : MapView 左欄可 toggle 的地圖組件卡。
halfmap : MapView 基本圖層或 map-layers 半高卡。
preview : 組件瀏覽平台的預覽卡，高約 170px，只顯示簡述、index、圖表 icon。
```

### 5.3 卡片結構

```text

  title = config.name
  small tag = update frequency
  source + data timeframe
  city tags
  favorite / delete / add / map toggle

Control
  city select
  chart type segmented buttons

Main Content
  active chart component
  loading spinner
  error state

Footer
  map/filter/history tags
  info button
```

### 5.4 Chart 切換邏輯

`config.chart_config.types` 是 chart type 陣列。第一個是預設 active chart。多於一個時，DashboardComponent 會渲染 segmented buttons，用 `chartTypes` 的中文名稱顯示。

## 8. Chart 類型完整目錄

來源：`chartTypes.ts`、`dashboardComponent/components/*.vue`、`backup_all_components.json`

現有樣本中共有 65 個 component，chart 使用次數最多的是 `BarChart`、`MapLegend`、`ColumnChart`、`DistrictChart`、`BarPercentChart`。

### 8.1 BarChart 橫向長條圖

檔案：`BarChart.vue`

- Apex type：`bar`
- 方向：horizontal。
- 預設 stacked。
- 適合：Top N 排名、分類總量、弱服務站點排行。
- 資料：通常是 two_d。
- 高度：依資料筆數動態 `40 + data.length * 30`。
- 地圖互動：支援 `byParam`、`byLayer`。

建議用於本案：

```text
弱服務站點排行：x = station_name, y = risk_score 或 service_score
```

### 8.2 ColumnChart 縱向長條圖

檔案：`ColumnChart.vue`

- Apex type：`bar`
- 方向：vertical。
- 支援 stacked 與 categories。
- 大於 12 筆資料時啟用自訂寬度工具列：加寬、縮窄、重置。
- 適合：站點 × 子指標、行政區 × 數值、時間年度分組。
- 地圖互動：支援 `byParam`、`byLayer`。

### 8.3 ColumnLineChart 長條折線圖

檔案：`ColumnLineChart.vue`

- Apex type：`line`，但 series 會被轉成第一組 column、第二組 line。
- 適合：兩條時間序列，一個作量、一個作趨勢。
- 若時間跨度超過三年，x 軸會切成年份 category。
- 不支援 map filter emit。

### 8.4 DonutChart 圓環圖

檔案：`DonutChart.vue`

- Apex type：`donut`。
- 會把 `series[0].data` 拆成 `labels` 與數值。
- 中央顯示總和。
- label 超過 7 字會截斷。
- 適合：類別占比、狀態分佈。
- 地圖互動：支援點擊篩選。

### 8.5 TreemapChart 矩形圖

檔案：`TreemapChart.vue`

- Apex type：`treemap`。
- 適合：多分類面積或量體比較。
- 資料：two_d。
- 視覺較擁擠，不適合站名很長或需要準確讀值的排行。

### 8.6 BarPercentChart 百分比長條圖

檔案：`BarPercentChart.vue`

- Apex type：`bar`
- `stackType: 100%`。
- 適合：正常/異常、可用/不可用、服務狀態組成。
- 若同一 config 也包含 `GuageChart`，會自動用第一色 + 灰色。
- 本案可用於：

```text
YouBike 有車 / 無車
YouBike 有位 / 無位
公車 ETA 正常 / 異常
```

### 8.7 GuageChart 量表圖

檔案：`GuageChart.vue`

- Apex type：`radialBar`。
- 以兩組 series 算百分比：第一組 / 第一組+第二組。
- labels 來自 `chart_config.categories`。
- 適合：單一 KPI 完成率、正常率。
- 注意：檔名是 `GuageChart`，不是 `GaugeChart`，config 也要拼 `GuageChart`。

### 8.8 RadarChart 雷達圖

檔案：`RadarChart.vue`

- Apex type：`radar`。
- 適合多面向能力比較。
- 本案若做單站詳情，可用四軸：

```text
取車、還車、公車、覆蓋
```

但現有樣本使用很少，整合風險略高於 Bar/Column。

### 8.9 HeatmapChart 熱力圖

檔案：`HeatmapChart.vue`

- Apex type：`heatmap`。
- x 軸 categories，y 軸 series name。
- 適合矩陣，例如：

```text
站點類型 × 時段
行政區 × 服務狀態
```

### 8.10 PolarAreaChart 極座標圖

檔案：`PolarAreaChart.vue`

- 自製 SVG / polar layout，不是 ApexCharts。
- 適合少量 categories 的多維比較。
- 視覺性強，但讀值精度較低。

### 8.11 TimelineSeparateChart 折線圖（比較）

檔案：`TimelineSeparateChart.vue`

- Apex type：`line`。
- 多 series 分開比較。
- x 軸 datetime。
- 適合歷史趨勢，不適合當下狀態卡。

### 8.12 TimelineStackedChart 折線圖（堆疊）

檔案：`TimelineStackedChart.vue`

- Apex type：`area`。
- 適合累積趨勢、總量變化。
- 本案可以之後用於歷史健康度趨勢。

### 8.13 BarChartWithGoal 長條圖（目標）

檔案：`BarChartWithGoal.vue`

- Apex type：`bar`。
- 顯示實際值與目標/警戒線概念。
- 適合「正常水位站點」這類達標率。
- 本案可用於「健康度 >= 65 的站數」。

### 8.14 IconPercentChart 圖示比例圖

檔案：`IconPercentChart.vue`

- 自製 icon grid。
- 固定 50 個 icon。
- 只適合兩組資料。
- icon 來自 Material Icons，例如 `man`、`woman`。
- 本案可用於「可服務站 / 弱服務站」比例，但不適合主圖。

### 8.15 IndicatorChart 指標圖

檔案：`IndicatorChart.vue`

- Apex stacked bar。
- 每個 category 只顯示最大值所在的 series，其他 series 轉成 0/1。
- 適合「每個測站目前落在哪個等級」。
- 本案可用於站點狀態分級：穩定、需觀察、偏弱、失效風險高。

### 8.16 TextUnitChart 文字數值圖

檔案：`TextUnitChart.vue`

- 純數值 tile，2 欄 grid。
- 資料格式是 `series` 陣列，每項用 `name`、`data[0]`、`icon`。
- 適合 KPI 摘要。
- 本案可用於：

```text
平均健康度 76
弱服務站點 7
觀測站點 110
歷史快照 N
```

### 8.17 DistrictChart 行政區圖

檔案：`DistrictChart.vue`

- 手刻臺北/新北行政區 SVG path。
- 不是 GeoJSON。
- 會將 `x` 對到固定行政區名。
- 支援 hover tooltip、click filter、fly to district。
- 適合行政區粒度，不適合捷運站粒度。

本案不建議用它當主圖，除非先把站點彙整成行政區平均健康度。

### 8.18 MetroChart 捷運行駛圖

檔案：`MetroChart.vue`、`MetroCarDensity.vue`、`taipeiMetroLines.ts`

- 不是地理路網圖，而是線性捷運行駛/車廂擁擠程度圖。
- 依 station id 判斷線別。
- 以 `A` / `D` 前綴拆方向。
- 每站顯示站名、line tag、上下行車廂密度。
- 適合列車擁擠程度，不適合我們的站區最後一哩服務健康度。

如果要用官方原生風格做本案捷運圖，建議新增 `MetroServiceChart.vue`，不要硬改 `MetroChart.vue`。

### 8.19 MapLegend 地圖圖例

檔案：`MapLegend.vue`

- 不是 chart，而是 map layers 的圖例與 filter 控制器。
- 可顯示 line/circle/fill 色塊，也可顯示 symbol icon。
- 有 `value` 時會顯示數值。
- 支援 `byParam`、`byLayer` filter。

本案若進 MapView，`MapLegend` 是必要搭配。

### 8.20 SpeedometerChart 儀表板圖

檔案存在：`SpeedometerChart.vue`

`chartTypes.ts` 有列，但註解寫「暫時不用」。`DashboardComponent.vue` 目前沒有 import/register 這個 chart，因此實務上不可直接用，除非補註冊。

## 10. Mapbox 圖層系統

來源：`mapConfig.js`、`mapStore.js`

### 10.1 地圖基本設定

```text
center: [121.536609, 25.044808]
maxBounds: [[121.2825, 24.6961], [122.0073, 25.2979]]
zoom: 9
minZoom: 9
maxZoom: 22
projection: globe
```

City view：

```text
taipei:      center [121.536609, 25.044808], zoom 12
metrotaipei: center [121.64080359050314, 24.980598540245936], zoom 9
default:     center [121.56376521148917, 25.086495621435404], zoom 10
```

### 10.2 支援 map type

來源：`mapTypes`

```text
line            線圖
circle          點圖
fill            面圖
fill-extrusion  立體面圖
symbol          符號圖
arc             立體弧線圖
voronoi         泰森多邊形
isoline         等高線圖
symbol-3d       三維捷運動態地圖
```

### 10.3 Source 模式

```text
geojson : 前端抓 /mapData/{index}.geojson
raster  : 其實多半是 vector tile / WFS，依 type 走不同分支
```

`mapStore.addToMapLayerList(map_config)` 流程：

```text
1. 產生 layerId = `${index}-${type}-${city}`
2. 若 layer 已存在：打開 visibility
3. 若 source = geojson：抓 /mapData/{index}.geojson
4. 若 source = raster：抓 GeoServer vector tile 或 WFS
5. 依 type 加 Mapbox layer / deck.gl layer / custom Three.js layer
```

### 10.4 通用 paint/layout

`maplayerCommonPaint` 與 `maplayerCommonLayout` 會依 type 合併到 layer config。

特別注意：

- `circle` 預設半徑會隨 zoom 變大。
- `circle-heatmap` 會加 blur / opacity。
- `line-wide`、`line-dash` 是 size 或 style 疊加。
- `symbol` 預設允許 overlap，icon-size 隨 zoom 調整。
- `fill` 透明度會隨 zoom 由 0.3 到 0.15。
- `fill-extrusion` 預設透明度 0.5。

### 10.5 圖層互動

Dashboard chart 可以透過 emits 觸發：

```text
filterByParam
filterByLayer
clearByParamFilter
clearByLayerFilter
fly
```

MapView 接收到後交給 `mapStore` 處理。

### 10.6 進階空間圖層

- `arc`：deck.gl ArcLayer / AnimatedArcLayer，適合 OD 或流量。
- `voronoi`：把點資料轉成 Voronoi cell line。
- `isoline`：先插值，再 marching square 產生等值線。
- `symbol-3d`：捷運 3D 動態地圖，載入 WFS 車輛資料、路線 GeoJSON、Three.js GLTF 模型。

本案暫時不需要 `symbol-3d`；捷運最後一哩比較適合 `line` + `circle` + `MapLegend`。

## 11. Chart / Map 組件關係

一個 component 可以同時有：

```text
chart_config.types = ["BarChart", "MapLegend"]
map_config = [circle layer, line layer]
map_filter = { mode: "byParam" | "byLayer" }
history_config = { range: [...] }
```

在 DashboardView：

- chart 顯示在卡片中。
- map_config 只以 footer tag 顯示，不會直接開地圖。

在 MapView：

- component 顯示為左欄控制卡。
- toggle 開啟後，map_config 才加到 Mapbox。
- chart 點擊可 filter map layer。

所以「要進儀表板」與「要進地圖交叉比對」是兩件事：

- 儀表板首頁：重點是 chart_data。
- 地圖交叉比對：重點是 map_config + GeoJSON layer。


## 12. 風格紅線

若要看起來像臺北城市儀表板，不要：

- 不要做大型 hero。
- 不要用行銷式漸層背景。
- 不要用大圓角卡片。
- 不要在卡片內放說明長文。
- 不要用太多自訂 icon 風格，優先 Material Icons。
- 不要使用明亮白底或彩色背景。
- 不要讓卡片超過既有高度規則。

應該：

- 保持深灰卡片、5px radius、1px border。
- 優先小字、短標題、密集資訊。
- 用 footer tag 表示空間資料/歷史資料/filter。
- 把資料來源、公式、情境放 MoreInfo。
- 把地理圖層交給 MapView。
